## Standards

No confirmed violation of the documented public-API, sandbox, read-only-access or privacy requirements in CONTRIBUTING.md, SECURITY.md, PRIVACY.md or docs/APP_STORE.md. Two optional P3 judgments follow; neither is a demonstrated behavior defect or hard standards violation.

- **Possible Duplicated Code, introduced:** [Application.swift:85](../../Sources/DownloadScroller/Application.swift#L85) sizes the window with `count * 58 + min(112, max(20, (count - 1) * 14))`. [NativeFanView.swift:148](../../Sources/DownloadScroller/NativeFanView.swift#L148) independently defines `stride = 58` and the same clearance formula at line 151. A shared fan-metrics value/helper would keep window sizing and row geometry coordinated. No present clipping defect was established.
- **Possible Primitive Obsession, introduced:** [NativeFanView.swift:23](../../Sources/DownloadScroller/NativeFanView.swift#L23) serializes folder/search/filter/sort/open generation into a pipe-delimited `query` string. Lines 78–81 compare it to decide when to reset scrolling/highlighting. An `Equatable` value with named fields would express this identity directly. No reachable collision was reproduced.

The contributor requirement to test Reduce Motion remains unmet in this review. This is a validation gap, not a claim that Reduce Motion is broken.

## Spec

**One P2 behavior defect, base-existing:** Escape fails to clear a search after arrow-key navigation.

Requirement: README.md:59 says **“Esc clears a search first.”** [Application.swift:210](../../Sources/DownloadScroller/Application.swift#L210) ends text editing on Up/Down, then its local event monitor handles Escape at line 220 by directly dismissing the panel. This consumes the event before the clear-search handler in [DockFanView.swift:70](../../Sources/DownloadScroller/DockFanView.swift#L70) can run.

Live reproduction in the sandboxed review copy:

1. Select the generated three-file folder with the real macOS picker.
2. Press Command-F, type `Recent`, then press Down.
3. Press Escape, reopen with Command-1, and inspect the query/results.
4. **Actual:** `Recent` remains in the field and only `03 Recent.txt` is listed. **Expected:** search is cleared before the fan is dismissed.

The retained-query failure is directly observed. The dismiss action is confirmed by source tracing; CUA's subsequent targeting can bring the window back, so the AX snapshot is not independent proof of a hidden-window interval. The same interception existed in base `464f1fd` (`Application.swift:126–143`), alongside the old SwiftUI clear-search handler. This is not a regression introduced by the reviewed diff.

Recommended fix: route Escape through one shared clear-search/close action, respecting editing and selection state, and add a responder-chain regression test for search → arrow → Escape. Product code remains unchanged in this review.

No unrequested user-facing scope or newly introduced spec deviation was confirmed. Source tracing covered newest-at-bottom ordering, independent newest-completed-file Dock selection, logo badge, 44-point icons, bottom search, outside-click/pin guards, read-only bookmarks and removal of list mode. Exact system-fan fidelity and physical-wheel feel are not established by source inspection.
